Overview

This project transforms the Global Superstore dataset into an India-focused retail analytics solution. Using Power Query, the data was cleaned and filtered before building a relational data model in Power BI. DAX was used to create custom measures and calculated columns, enabling interactive dashboards that highlight sales performance, customer behavior, profitability, shipping efficiency, and regional trends.

Tools & Features

Power BI

Designed an interactive three-page dashboard with KPI cards, charts, slicers, and drill-down analysis.

Power Query

Cleaned and transformed the Global Superstore dataset to include only Indian retail transactions.

DAX

Built calculated columns and measures to deliver meaningful business metrics.
