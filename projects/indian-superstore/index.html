Overview

This project transforms the Global Superstore dataset into an India-focused retail analytics solution. Using Power Query, the data was cleaned, filtered, and reshaped into Indian transactions before building a relational data model in Power BI. DAX measures and calculated columns power the interactive dashboard, surfacing sales performance, customer behaviour, profitability, shipping efficiency, and regional trends at a glance.
